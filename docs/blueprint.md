# **App Name**: KopiVerse

## Core Features:

- Outlet Locator: Find Kopi Dua Darjat locations near you.
- Menu Display: Browse the Kopi Dua Darjat menu.
- Promotions Showcase: View current promotions and offers.
- Brand Story Generator: Generates compelling brand stories that align with Kopi Dua Darjat's identity, for different types of publications or media using a tool.
- Franchise Inquiry Form: Submit interest in becoming a franchisee.
- Blog: Share news, updates, and stories.
- Contact Information: Provide contact details for customer inquiries and partnerships.

## Style Guidelines:

- Primary color: Kopi Brown (#4B2E2A) to evoke a warm, rustic feel.
- Background color: Cream (#F4EDE6) to create a soft, inviting backdrop, on the same hue as the primary but heavily desaturated.
- Accent color: Burnt Sienna (#D97A3A) for highlights and calls to action; it is an analogous color to the Kopi Brown and sufficiently contrasting.
- Headings: 'Playfair' (serif) for an elegant, high-end feel; limited use.
- Body text: 'PT Sans' (sans-serif) for modern readability in body text.
- Use warm, hand-drawn style icons representing coffee beans, cups, and Malaysian motifs.
- Cards with rounded corners and soft shadows will be used throughout to create a layered, touchable feel.
